# CHE110 CA1 GROUP PROJECT
## E-Waste Collection & Management Platform

### 📌 Overview
This web application provides a clean and easy-to-use interface for users to safely schedule e-waste pickup requests and locate nearby collection centers.

### 🛠️ Key Features
- Pickup Request Form: Allows users to submit their name, contact details, e-waste category, and pickup address.
- Form Interactivity: Includes custom interactive response messages upon form submission.
- Collection Center Locator: Displays nearby e-waste collection hubs along with location details and operating hours.
- Responsive Styling: Clean UI designed with custom CSS using a green eco-friendly visual theme.

### 💻 Tech Stack
- HTML5: Page structure and form elements.
- **CSS3:** Custom layout styling, color schemes, and component cards.
- JavaScript: Form submission handling and event listeners.
